Writing records

A RecordWriter{T} writes records of type T to a sink, and is the mirror of a RecordReader{T}. A record type says how one record is written with a method of RecordIO.write_record, as it says how one is read with RecordIO.read_record. The Line record type of Record types is written as its bytes and a newline:

RecordIO.write_record(sink, line::Line) = RecordIO.write_line(sink, line.bytes)

write writes a record, several, or all those of a vector or of a reader, and returns the number of bytes written. The records of a reader of views are each written before the next is read, so copying a file allocates nothing for each record:

text_of_lines = join(["first", "second", "third"], '\n') * '\n'
output = IOBuffer()
writer = RecordWriter{Line}(output)
write(writer, RecordReader{LineView}(IOBuffer(text_of_lines)))
19

The writer counts the records and the bytes that it has written:

RecordIO.number(writer), RecordIO.offset(writer), String(take!(output))
(3, 19, "first\nsecond\nthird\n")

The writer trusts its records, and writes them as they are. What the specification of a format says of a record is checked when it is asked for, with RecordIO.validate.

Sinks

A sink is an IO or a BufferIO writer, and close(writer) closes it. Given a function, a writer is closed when the function returns or throws, and open makes a writer of a file, to write it or, with append = true, to add to it:

path = tempname()
open(RecordWriter{Line}, path) do writer
    write(writer, collect(RecordReader{Line{Owned}}(IOBuffer(text_of_lines))))
end
read(path, String)
"first\nsecond\nthird\n"

What a record type writes

write_record(sink, record) writes one record with what ends or frames it, and returns the number of bytes. These write to any sink, and allocate nothing:

  • RecordIO.write_bytes: a vector or a memory view of bytes, or a range of it;
  • RecordIO.write_line: the same, and a newline;
  • RecordIO.write_le: an integer, in little-endian order, as binary formats store them;
  • RecordIO.write_length_prefixed: bytes after their length, the framing that RecordIO.LengthPrefixed reads.

A method of write_record for anything else that a file holds, such as a line of a header, is written by the same write, and is counted in the bytes of the writer, but not in its records.

Writers of record packages

A package's writer is a subtype of RecordIO.AbstractWriter{T} that holds a RecordWriter{T} in a field named records, as its reader holds a RecordReader{T}. It needs only a constructor that takes the sink first, where it may write a header, and has write, close, flush, open and the form that takes a function from its supertype:

struct LineWriter{S} <: RecordIO.AbstractWriter{Line}
    records::RecordWriter{Line, S}
end

LineWriter(sink) = LineWriter(RecordWriter{Line}(sink))

output = IOBuffer()
writer = LineWriter(output)
write(writer, RecordIO.parse_record(LineView, codeunits("only")))
String(take!(output))
"only\n"
